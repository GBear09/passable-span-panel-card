# Changelog

All notable changes to **Passable Span Panel Card** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.2] - 2026-10-02

### Changed
- **Corner Radius & Clipping**: Restored `overflow: hidden;` on `<ha-card>` to guarantee crisp, clean corner clipping across all Lovelace dashboard themes.
- **Registry Metadata**: Standardized `window.customCards` configuration with `documentationURL`.

## [1.1.1] - 2026-09-21

### Fixed
- Outage alert indicator and breaker priority toggle service calls.

## [1.1.0] - 2026-09-18

### Added
- Breaker priority controls and real-time power telemetry.
